# Changelog

## 0.1.0 (unreleased)

The first version: one host, one binary, a calm live view of canonical logs.

- **Ingest.** Docker containers from the local socket (named by swarm service → compose service → container, replicas merged; finds Docker Desktop, OrbStack, Colima, rootless sockets and the current `docker context`). HTTP pushes from Vector, Fluent Bit, OTLP/HTTP logs + traces, NDJSON/curl and `quiet pipe`, with send-only `qi_` ingest tokens, body and rate limits.
- **Stream.** One source at a time over a WebSocket, newest at the bottom (or top), level toggles and text filter, keyboard navigation, field card, reconnect with backoff.
- **Storage.** SQLite (WAL) hourly partitions with FTS5 and an index of every correlation id; 24h window by default (1h–7d), a disk cap that drops the oldest hour first, purge, per-source windows.
- **Flows.** Every line sharing an id, stitched across sources (request → job → retries, two hops, bounded), OTLP span trees, step graph + timeline, child steps from `wideEvents`.
- **Search & export.** Words, phrases, `level:`, `source:`, `id:`, `key:value` filters, histogram, group by flow; NDJSON / JSON / CSV export with PII masking and a 15-minute read-only `qx_` Copy-curl token; very large exports are prepared on the server with progress, Cancel and an "Export ready" toast.
- **Accounts.** First-run owner, members via copy-link invites, argon2id passwords, cookie sessions with CSRF, reset links and `quiet admin reset-password`.
- **Settings.** General (instance name, timezone, stream direction), Flow id order (keys, order, match by key or value), Storage (usage, partitions, volume by source, projection, window, cap, purge), per-source settings (display name, hide, pause ingest, window, id keys, default level, PII masking, muted lines, purge, remove that also revokes its bound tokens with Undo) with a Rejected tab; UI values override the CLI/env defaults.
- **Muted lines in search.** Hidden from Search by default; "Include muted lines in search" per source (inherit / on / off) and in Settings → General (default off, `QUIET_SEARCH_INCLUDE_MUTED`) shows them dimmed with a `muted` tag ("N muted lines included · Hide"). Show muted / Hide is a one-off `muted=include|hide` URL override; the stream still always hides them; exports from search follow the search's muted state (`/api/export?muted=auto|hide`).
- **System.** `/api/system` and app banners for Docker unavailable, disk near/at the cap, a nearly full data volume, store write errors and refused ingest requests. In-memory live lines are capped by a shared memory budget (`QUIET_RING_MEMORY`, 64MB).
- **Click-to-copy values.** In the field card's Fields tab, a value underlines on hover and copies on click (or Enter/Space): strings unquoted, numbers/bools as text, objects and arrays as JSON, always the full value, with a "Copied <key>" toast. Clicking elsewhere on the row still picks the field for Filter by value.
- **Diagram tab.** The field card gets a 4th tab, Fields · JSON · Raw · Diagram: the line's objects and arrays as cards of typed `key: value` rows laid out left → right (or top → down) on a dotted canvas with pan and zoom. The card grows over the flow column (header stays); another tab or `Esc` shrinks it back, Full screen hides the sidebar. Click a value to copy; hover or right-click for Copy value, Copy path, Filter by value, Exclude value, Highlight this value (marks the same value elsewhere) and Use as a flow id… (stages the key in Settings → Flow id order). `−`/`+` handles fold branches; `/` searches keys and values (`2 / 5`, opens folded branches with a match, dims the rest). Large lines: past depth 3 starts collapsed, arrays show 5 items ("+ 9 more · showing 5 of 14"), and over ~200 keys / 32 KB a notice with Expand all and a minimap appears. Toolbar: fit, full screen, zoom, Export image (PNG), search, copy JSON, settings (direction, collapse depth, array cap, wrap, remember collapsed; saved in this browser). Plain-text lines keep JSON and Diagram visible but disabled with a tooltip. Stream's row preview gets a Diagram button (`D`). Lazy-loaded as its own chunk.
- **Custom source groups.** Owners make their own groups from Sources (New group, with an optional checklist of sources), move a source in from its ⋯ menu (Move to group › a group, New group…, or Automatic to reset it), and rename, reorder (Move up / down) or delete a group from its header ⋯ menu. A group you assign wins over automatic grouping (`quiet.group` → Compose project → Swarm stack → Standalone) and custom groups sit above the automatic ones in Auto and Label modes, on Sources, the sidebar, the stream source picker and ⌘K. Deleting a group sends its sources back to automatic grouping and never deletes lines. Mode Off keeps the groups and shows one flat list; they come back when grouping is on. `QUIET_GROUP_BY` locks the mode only. Saved server-side (`/api/source-groups`); members see the groups but can't edit them. Sources also gets a Custom group filter, a rules hint and an "N moved to …" note on the automatic group; Settings → General shows the custom group count.
- **No empty-state flash while filters load.** Changing a stream filter (level chips, text, `key:value` chips) keeps the previous rows dimmed with an "Updating…" spinner until the new filter's backlog arrives, or shows skeletons when there were none; "No lines match" appears only once the server has answered with zero lines. Frames from the previous filter's socket are dropped, and the "N of M lines match" counts wait for the new filter's numbers. Search keeps the previous results dimmed while a new query runs (skeletons if the previous query was empty). Sources shows skeletons while the list loads instead of "Nothing connected yet", and the Erroring tab says "Checking error rates…" until every source is counted instead of "No sources match"; a source's page says "Loading…" instead of "No line from … yet" while sources load.
