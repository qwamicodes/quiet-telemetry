# v0.1.1 plan

23 November 2026 · scope agreed: every v0.1.1 screen, storage and retained history, redaction before storage, Node · pino kept, "seen" state per account.

v0.1.1 makes the canonical completion event (`docs/logging-guide.md`) the contract quiet reads, stores and teaches. It also adds retained history in object storage. Records in the v0.1.0 format keep working everywhere. Designs: portal v0.1.0 (pages 03–06, 11 and v0.1.1 · 00 · What's new) and "quiet · v1.1 storage & retention". Screen review: `docs/logging-paper-review.md`.

One slice per PR, `make check` green, CHANGELOG updated in each.

## Out of scope

- SLO/SLA measurement and reports: v0.5.0. v0.1.1 only collects goals in the prompt.
- Rewriting already-stored records for redaction.
- Native queue adapters inside quiet. The prompt maps each user's queue in their own codebase.
